# CodeForge — Learning Platform

A modern and responsive static learning-platform website built using HTML5 and CSS3 as part of the YuvaIntern Frontend Web Developer Week 1 task.

## Live Demo

https://newayushgupta-web.github.io/CodeForge/

## Project Overview

CodeForge is a clean and modern learning-platform landing page designed to present practical learning paths for aspiring developers.

The website focuses on clear visual hierarchy, responsive layouts, smooth interactions, and a simple user experience.

## Features

- Responsive navigation bar
- Modern hero section
- CodeForge custom branding
- Learning path cards
- Interactive hover effects
- Feature section
- Call-to-action section
- Responsive mobile layout
- Smooth scrolling
- CSS animations
- GitHub Pages deployment

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Media Queries
- CSS Animations
- GitHub Pages
